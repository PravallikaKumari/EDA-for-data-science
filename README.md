# EDA-for-data-science

## Project Overview
This project focuses on Exploratory Data Analysis(EDA) using Python to understand, clean and analyze, visualize data. The goal is to identify patterns and generate meaningful insights from the dataset.

## Project Workflow
-Raw data collection and exploration

-Data cleaning and preprocessing

-Exploratory Data Analysis

-Data visualization

-Feature analysis

-Testing with sample data

## Technologies Used
-Python

-Pandas

-Numpy

-Matplotlib

-Seaborn

## Project Files
- 'Raw_Data/'-Original dataset

- 'Clean_Data/'-Cleaned and processed dataset

- 'Code/'-Python code used for EDA

- 'test.csv/'-Test/sample data

- 'EDA_Report.pdf'-Project report

## Key Skills
-Data Cleaning

-Data Preprocessing

-Exploratory Data Analysis

-Data Visualization

-Feature Analysis

-Python for Data Analysis

## Project Outcome
The project demonstrates practical experience in data cleaning, data preprocessing, exploratory data analysis, and data visualization using python and commonly used Data Science libraries.
